## Quick Start

1. Run console-based programs with Node.js:
   ```bash
   node phase-1/prog-01.js
   node phase-2/prog-21.js
   node phase-3/prog-41.js
   ```
2. Open browser-based program pages directly in a browser (mainly in `phase-3`, for example `prog-53.html` to `prog-57.html` and `prog-59.html`).

## Notes

- Each phase folder contains programs grouped by the phase syllabus.
- Console outputs include execution metadata (date/time, session token, and verification hash) for traceability.
- Some browser examples expect specific HTML elements to exist before running their JavaScript files.
