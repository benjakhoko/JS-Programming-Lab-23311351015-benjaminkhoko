## Topics Covered

### Functions (prog-21 to prog-30)
- Function declarations and expressions
- Arrow functions (ES6)
- Function parameters and default values
- Hoisting behavior
- Scope and closures
- Callback functions
- Higher-order functions
- Recursion
- IIFE (Immediately Invoked Function Expressions)
- Function context control (call, apply, bind)

### Objects and Object-Oriented Programming (prog-31 to prog-40)
- Object literals
- Object methods and the 'this' keyword
- Constructor functions
- Prototypes and prototype chain
- Prototypal inheritance
- ES6 class syntax
- Class inheritance
- Property descriptors
- Object static methods (Object.keys, Object.values, Object.entries, Object.assign)
- Getters and setters
- Private fields (ES2022+)

## How to Run

## Key Learning Outcomes

By completing Phase 2, students will:
- Master JavaScript function declarations, expressions, and modern arrow function syntax
- Understand scope, closures, and the JavaScript context ('this' keyword)
- Learn callback and higher-order function patterns
- Understand prototypes and prototypal inheritance in JavaScript
- Learn ES6 class syntax and modern OOP patterns in JavaScript
- Work with advanced object manipulation techniques
- Implement encapsulation using getters, setters, and private fields
